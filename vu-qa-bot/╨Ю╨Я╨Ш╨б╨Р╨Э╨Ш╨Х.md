## Как устроено ядро (`vu_testdata.py`)

```
Identity (ФИО + ДР + пол)          ← parse_identity() / parse_me()
        │
        ├─ region_code   ← выбирается кнопкой в боте (85 кодов ГИБДД)
        ├─ birth_place   ← задаётся пользователем
        └─ valid_now     ← в боте всегда True (срок не истёк)
        ↓
   make_valid()  ────────────────→  LicenceRecord
        │                            • поля 1–9 лицевой стороны
        │                            • back_table (оборотная)
        │                            • synthetic / expected_valid / broken_rule
        ↓
   make_mutated(name)  ──────────→  та же запись, но сломано РОВНО ОДНО правило
```

**Ключевые инварианты** (проверяются тестами):
- `translit(x_ru) == x_lat` для 4 пар полей (таблица МВД/ИКАО Doc 9303)
- срок = выдача + ровно 10 лет
- набор категорий замкнут по таблице зависимостей (`B → B1, M` и т.д.)
- возраст на выдаче ≥ порога строжайшей категории
- `back_table.keys() == set(categories)`
- первые две цифры серии = код подразделения в поле 4c
- `is_synthetic(rec)` истинен для ВСЕХ записей

## Мутаторы (`MUTATORS`, декоратор `@mutator`)

`translit_mismatch` · `expiry_not_plus_10y` · `front_back_number_mismatch` ·
`category_dependency_broken` · `front_back_category_mismatch` · `underage_at_issue` ·
`invalid_authority_region` · `unknown_category_symbol` · `issue_date_in_future` ·
`special_marks_after_issue` · `back_open_after_expiry`

Каждый ломает ровно одно правило и приводит побочные поля в согласованное состояние —
иначе запись нарушила бы два правила сразу и перестала быть точечным тестом.

## Запуск

```bash
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt

# генерация без Telegram
./.venv/bin/python vu_testdata.py --valid 10 \
    --identity "ЩЕРБАКОВ ДМИТРИЙ ВАЛЕНТИНОВИЧ 14.03.1988" --region 77 \
    --birthplace "Г. ВОРОНЕЖ" --valid-now

# метрики (точка входа CI, код 0 при precision=recall=1.0)
./.venv/bin/python eval_rules.py --valid 500 --mutated 1100

# тесты приёмки
./.venv/bin/python test_vu.py

# сам бот (нужен .env)
./.venv/bin/python vu_qa_bot.py
```
